# SERIOUS SVEN
Repo for a copy of the abandoned Serious Sven scripts by Zode
Since this was nowhere to be found and was shared by Zode at one point, I've made this github repository to archive it in its working state.

CREDITS:
Aperture & Zode (serious sam scripts)
DGF (kamikaze model)
Descen (other models)

KNOWN BUGS:
- missing models for some armor, health and weapons. Scripts fail if they are missing sometimes so I have added placeholders for the armor/health that was missing. And added completed p_ weapons that were missing (by Garompa)
- The powerups bugs the ammo hud if you switch between scripted weapons. There is something wrong with the hud display of the powerups timer and icons that mess around with it. It only lasts during the powerup timeframe
